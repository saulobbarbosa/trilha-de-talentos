# Trilha de Talentos

Crie as telas necessários para o projeto abaixo:

Resumo do projeto:
Uma plataforma onde o RH cadastra o treinamento com vagas e datas, líderes reservam vaga para o seu time, o instrutor faz a chamada no dia (com reconhecimento facial para evitar fraude de presença) e, ao final, o sistema gera um certificado digital com código de verificação, para que qualquer pessoa possa conferir se aquele certificado é válido.

Telas:
Tela de Login (para funcionario, para RH, para lider e para instrutor, serão niveis diferentes de acesso)
Tela de cadastro e gerenciamento  de treinamentos (somente para RH)
Tela para lideres fazerem a reserva (somente para lider de equipe)
Tela de chamada para instrutor com reconhecimento facial para validar a presença
Tela de visualição de treinamentos (para o funcionario visualizar seus certificados) 

Considerando os seguintes fatores:
- Utilize a logo em anexo e as seguintes cores hexadecimais para a paleta de cores: #00339F #00B5AC #FFFFFF
- Não é necessário criar nenhuma funcionalidade, pois será implementado em uma fase seguinte
